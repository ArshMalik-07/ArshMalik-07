🚗 SmartRide — Dynamic Ride Pooling & Fair Fare Allocation System
A ride-pooling web app prototype that solves a real fairness problem: instead of splitting a shared cab's total fare equally among passengers, SmartRide breaks the route into segments and calculates each rider's fare based on the exact segments they actually travelled.
Tech: HTML5 • CSS3 • JavaScript (frontend-only prototype)
Status: Core fare-allocation logic complete — GPS tracking, live backend, and payments are next on the roadmap.
